## What I Learned

- Production Terraform tests should be self-contained and must not depend on
  ignored local tfvars.
- Path-filtered CI should cover production environment roots in addition to
  reusable modules.
- A Lambda alias does not provide operational rollback for an API until the API
  actually invokes the alias.
- Lambda version publication can be introduced separately from traffic routing,
  reducing migration risk.
- Keeping the original invoke permission during the first alias-routing change
  provides a safer staged migration.
- Saved Terraform plans should become obsolete whenever source code changes.
- A production apply can be strongly bounded by commit SHA, CI run, tfvars
  SHA256, plan SHA256, Terraform state lineage/serial, and live AWS baseline.
