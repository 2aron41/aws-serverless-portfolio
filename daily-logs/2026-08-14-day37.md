## What I Learned

- Frontend validation improves UX but Lambda remains the real security boundary.
- Values should be normalized before business-rule validation.
- Automated behavior tests are stronger than static grep checks alone.
- Production tests should fail before AWS authentication whenever possible.
- CI expectations must respect workflow path filters.
- A successful deployment workflow should still be independently verified.
- CloudFront/S3 file hashes can prove the live site matches the repository.
- Browser caching can temporarily make a successful deployment appear stale.
- End-to-end validation must test the actual browser path, not only the backend API.
- GitHub Actions + OIDC keeps deployment credentials out of the repository and local workflow.
