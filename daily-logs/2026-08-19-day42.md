## What I Learned

Operational monitoring should distinguish between server failures and
abnormal client traffic.

API Gateway 5xx monitoring detects server-side failures, while 4xx
monitoring provides a separate signal for sustained client-error traffic
that may indicate abuse, malformed requests, broken clients, or other
unexpected request patterns.

A threshold should not be interpreted from a single request. Requiring
multiple breaching evaluation periods reduces sensitivity to isolated
client mistakes.

I also reinforced the deployment workflow:

module tests -> production impact review -> commit -> CI -> fresh reviewed
production plan -> exact saved-plan apply -> live policy verification ->
Terraform convergence -> documentation.
