## Design Audit

The inquiry Lambda is packaged by Terraform from:

`lambda_src/inquiry_handler.py`

using `archive_file` and `source_code_hash`.

With the alias architecture enabled, the Lambda uses:

`publish = true`

Therefore, a legitimate handler code change naturally publishes a new
immutable numbered version.

No artificial version or manual `publish-version` command was required.

## Selected Version-2 Improvement

Added privacy-safe validation observability.

Invalid inquiry requests continue returning the generic public response:

`{"message": "Invalid inquiry request."}`

The Lambda now emits a warning containing only the predefined validation
category.

Visitor-submitted name, email, message, and raw request body are not
intentionally logged by this feature.
