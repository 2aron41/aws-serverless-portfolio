## What I Learned

- Existing infrastructure should be inspected before adding new security services.
- API Gateway already provided useful server-side throttling, so Day 40 did not require WAF, CAPTCHA, DynamoDB, or new Lambda concurrency controls.
- Hard-coded security controls are harder to tune and reuse than explicit validated Terraform variables.
- Defaults can preserve production behavior while improving module design.
- A zero-change production plan is strong evidence that a refactor preserves infrastructure behavior.
- Negative Terraform tests are useful for enforcing safe configuration boundaries.
- Frontend cooldowns and API Gateway throttling solve different problems and work better as layered controls.
- Server-side throttling reduces request rate but does not provide identity-aware abuse protection or idempotency.
