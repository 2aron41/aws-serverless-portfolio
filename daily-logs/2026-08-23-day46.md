## What I Learned

- Lambda alias infrastructure can be introduced separately from traffic
  migration, reducing production risk.
- API Gateway Lambda integrations can target an alias-qualified Lambda
  `invoke_arn` without replacing the API integration resource.
- A Terraform test may need a plan-time override when asserting against
  computed resource attributes.
- A precise RED should fail because the behavior is wrong, not because a value
  is unknown during the plan.
- Separating permission cleanup from traffic migration makes the rollback
  boundary easier to reason about.
- Saved Terraform plans should be generated only after the exact source commit
  and required CI runs are green.
